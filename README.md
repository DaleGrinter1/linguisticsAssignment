# Linguistics and LLMs Website

Static educational website for a university project about how morphology, syntax, semantics, and pragmatics relate to Large Language Models.

## Files

- `index.html` - single-page website content
- `styles.css` - responsive classroom-style layout
- `assets/` - copied project images used by the website
- `essay-2.docx` - original essay source document

## Preview

Open `index.html` in a browser.

## GitHub Pages Deployment

1. Create a new GitHub repository for this folder.
2. Push this local repository to GitHub.
3. In GitHub, open Settings, then Pages.
4. Set the source to the `main` branch and the root folder.
5. Use the published GitHub Pages URL as the hosted submission link.
